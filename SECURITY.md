# Security

Every skill in this repo is plain text: one `SKILL.md` per skill, sometimes with more `.md` files beside it. Nothing here runs code on your computer, and [scripts/check.sh](scripts/check.sh) fails any change that adds a file that isn't Markdown inside `skills/`.

A skill only reaches what you've already connected to your own Claude (for example, meeting-prep reads your email only if you've connected Gmail). Each skill's page says what it touches.

If you find something that could hurt someone who uses these, please email support@vntos.io instead of opening a public issue. I'll reply within two business days.
